# API

Interactive documentation is generated by FastAPI:

- Swagger UI: `/docs`
- ReDoc: `/redoc`
- OpenAPI schema: `/openapi.json`

When using Docker Compose these URLs are available through the frontend origin as well, for example `http://localhost:8080/docs`.

## Conventions

- JSON request and response bodies
- Cookie authentication; send `credentials: "include"` from browsers
- Errors use `{ "detail": "..." }` or, for duplicate bookmarks, `{ "detail": { "code": "duplicate", "message": "...", "existing": { ... } } }`
- List endpoints that can grow large are paginated with `page` and `page_size`

## Authentication

| Method | Path | Notes |
| --- | --- | --- |
| POST | `/api/auth/register` | Creates the user and sets cookies |
| POST | `/api/auth/login` | Sets cookies |
| POST | `/api/auth/logout` | Clears cookies |
| GET | `/api/auth/me` | Current user |
| POST | `/api/auth/refresh` | Rotates tokens using the refresh cookie |

## Bookmarks

| Method | Path |
| --- | --- |
| GET | `/api/bookmarks` |
| POST | `/api/bookmarks` |
| POST | `/api/bookmarks/preview` |
| GET | `/api/bookmarks/{id}` |
| PATCH | `/api/bookmarks/{id}` |
| DELETE | `/api/bookmarks/{id}` |
| POST | `/api/bookmarks/{id}/visit` |
| POST | `/api/bookmarks/{id}/archive` |
| POST | `/api/bookmarks/{id}/restore` |

`GET /api/bookmarks` accepts `folder_id`, `tag`, `favorite`, `archived`, `search`, `sort`, `order`, `page`, `page_size`, and `recent=added|visited`.

A later browser extension can create bookmarks with `POST /api/bookmarks` and `{ "url", "title" }` once an additional client credential is added.

## Import and export

`POST /api/import/bookmarks` accepts a Netscape HTML file (`multipart/form-data`, field name `file`).

`GET /api/export/bookmarks` returns a Netscape HTML download.
